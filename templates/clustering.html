Why Clustering Matters

Unlike regression and classification, clustering does not predict a target value. Instead, it discovers natural patterns in humanitarian data.

About the Model

This application uses a KMeans Clustering model trained on humanitarian indicators from six countries. Before clustering, all features were standardized using a StandardScaler to ensure that every indicator contributed equally.
