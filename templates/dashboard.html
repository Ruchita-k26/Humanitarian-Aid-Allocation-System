Project Goal

The Humanitarian Aid Allocation System leverages Machine Learning to support humanitarian decision-making by estimating the number of People in Need (Final PiN), classifying humanitarian severity, and grouping regions with similar humanitarian conditions. A total of 21 machine learning algorithms (11 regression, 8 classification and 2 clustering) were evaluated, and the best-performing model from each task was deployed in this Flask application.
