About This Project

An AI-powered decision support system designed to help humanitarian organizations prioritize aid using Machine Learning.

Project Overview

Humanitarian crises caused by conflicts, climate change, food insecurity, and disease outbreaks affect millions of people worldwide. Organizations often need to make rapid decisions about where limited resources should be allocated.

This project applies Machine Learning techniques to predict People in Need (PiN), classify humanitarian severity, and identify regions with similar humanitarian conditions. These insights can support faster, more data-driven humanitarian planning.

Problem Statement

Humanitarian agencies manage large volumes of assessment data across multiple sectors such as education, health, shelter, food security, nutrition, protection, and water & sanitation. Analyzing this information manually is time-consuming and may delay critical decisions.

The goal of this project is to use Artificial Intelligence to transform humanitarian data into actionable insights that support better resource allocation.

Key Features

Regression

Predict the estimated number of People in Need (Final PiN).

Classification

Predict humanitarian severity levels using Gradient Boosting.

Clustering

Group regions with similar humanitarian conditions using KMeans clustering.
